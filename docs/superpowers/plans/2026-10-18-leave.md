# Leave (work order §4.7) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Port legacy's leave module onto ERP employees, the approvals engine and scoped RBAC: types, balances, requests with attachments, HR excuses, return to work and the register.

**Architecture:** A new `app/Modules/Leave` (routes at `/api/leave`, self-service routes in `app/Modules/Me/routes.php`) that depends on Attendance (calendar, `ApprovedLeave` contract) and Approvals (engine); `LeaveRequest` is the engine's `Approvable`. A shared polymorphic `attachments` table in `app/Shared` holds files on the private disk. Three slices, each green on its own.

**Tech Stack:** Laravel 12, PHP 8.3, PHPUnit feature tests with `RefreshDatabase`, Sanctum, Pint.

**Spec:** [`docs/LEAVE_BUILD.md`](../../LEAVE_BUILD.md) (approved 2026-10-18). Read with [`APPROVALS_ENGINE_DESIGN.md`](../../APPROVALS_ENGINE_DESIGN.md) §5, §7, §10 and legacy `../Raqi-App/app/Http/Controllers/LeaveRequestController.php` — legacy is the reference for every rule this plan does not restate.

## Global Constraints

- **No git writes.** Do not commit, stage or branch; each slice ends at a checkpoint where the user decides on a commit (memory: committing is the user's decision; a plan's commit steps do not count).
- **Re-check `git status` before editing a shared file** — another agent may edit this tree concurrently.
- Every file starts `declare(strict_types=1);`; match the house comment density (a docblock saying *why*, citing the decision: Q-numbers, D-numbers, `LEAVE_BUILD.md §n`).
- Every response goes through `ApiRespond` (`success`, `created`, `paginated`); page size through `$this->perPage($request)`.
- Every refusal is Arabic. A business refusal is `LeaveException` (implements `App\Shared\Exceptions\DomainException`, 422 by default). **A `DomainException` carries no payload (C17)**: where legacy returned the balance or the attended dates beside its message, put the figures **in the message**.
- Row scope: `RequestRowScopes::forUser($user, $permission)->covers($employee->department_id)` through the employee's **current** unit (D6); out of reach is `OutOfScope::deny(...)` → 403 `out_of_scope`; `can:` on the route so it runs before the body is read.
- Every new permission is classified in `App\Modules\Auth\Support\PermissionReach` and listed in `PermissionSeeder` (with an Arabic label), and `PermissionSeederTest::TOTAL` / its expected list and `PermissionReachTest`'s company-only list are updated.
- Every new audited model gets a morph alias in `AppServiceProvider` (`MorphMapTest`), an Arabic label in `AuditTargetStub`, and a gate in `AuditLogDetailResource` (leave types → `leave.types.update`; balances → `leave.balances.view`; requests and attachments → `leave.requests.view`).
- Sorts are one `sort` key with an optional leading `-` (C30), unknown keys 422; lists paginate on the builder.
- Resources never query: services eager-load a `RENDER_RELATIONS` constant.
- Files: `.php` with LF endings (the Python-on-Windows edits of step 2 once wrote CRLF — check `git ls-files --eol`).
- Run the whole suite and `vendor/bin/pint --test` at the end of every slice; after each task, mutate each new guard and watch a test fail (the house's mutation check).

## Review Focus

1. **A refused filing leaves nothing behind** — when the engine refuses the chain (vacant HR post, approver without an account) after the files were written, the request row, the approval and every stored file are gone. Test in Task 6.
2. **Year boundary** — a leave from 2026-12-30 to 2027-01-02 is charged wholly to 2026 (start year), and the 2027 balance is untouched. Test in Task 2.
3. **Two pending requests together exceeding the balance** — both file (pending reserves nothing); the second final approval is refused by the guard with the subject's message. Test in Task 5.
4. **A withdrawn or rejected request no longer blocks its dates** — the same span can be filed again immediately. Test in Task 7.
5. **A colleague cannot read another's leave or its files** — not by id on `GET /api/leave/requests/{id}`, not by attachment id under someone else's request (scoped binding → 404). Test in Task 7.
